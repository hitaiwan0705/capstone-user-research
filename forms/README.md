# 回家作業表單（可回收數據）

一份表單「畢專使用者研究｜回家作業」，對應作業規範的 5 個必要指標，共 47 題，下週上課前繳交。題目相同，提供兩種建立方式。

| 區段 | 內容 |
|---|---|
| 基本資料 | 組別、畢專名稱、組員、類型 |
| 指標 ① Persona 假設 | 行為與情境、目標與障礙、資訊管道、Anti-persona、證據狀態 |
| 指標 ② 情境與旅程 | 問題情境、Mini CJM、回饋迴路、CJM 圖檔連結、關鍵痛點象限 |
| 指標 ③ 假設卡與門檻 | 假設、策略、指標、門檻、**門檻寫下日期**、最危險假設 |
| 指標 ④ AI 前測 | 工具、**前測日期**、對話紀錄連結、3 題與 AI 回答 |
| 指標 ⑤ 真人實測與校準 | 受訪者概況、**訪談日期**、3 題真人回答、落差、洞察、Keep／Revise／Pivot |
| 揭露與同意 | AI 使用揭露、AI 信任度、教學研究同意 |

三個日期題用來確認順序：門檻 ≤ AI 前測 ≤ 真人訪談。

## A. Google 表單（全自動，含回應試算表）

1. 開啟 https://script.google.com ，按「新專案」。
2. 刪掉預設內容，貼上 `google-forms.gs` 全部程式碼，存檔。
3. 上方函式選單選 `createAllForms`，按「執行」，依畫面完成授權。
4. 打開「執行紀錄」，複製「填答網址（給學生）」。表單和回應試算表都在您的 Google 雲端硬碟根目錄。
6. 建議在表單設定開啟「收集電子郵件地址」並限制校內帳號，方便核對組別。
5. 若表單顯示「未發布」，進入編輯頁按右上角「發布」。

## B. Microsoft Forms（Teams）

1. 到 https://forms.office.com ，選「快速匯入」，上傳 `回家作業_MicrosoftForms匯入.docx`。
2. 匯入後檢查：標註【評分題】改成「評分」、【Likert 題】改成「Likert」、【日期題】改成「日期」（快速匯入不會自動辨識這三種）。
3. 在 Teams 頻道用「+ 新增索引標籤 → Forms」加入表單。回應可在 Forms 的「在 Excel 中開啟」下載。

## 修改題目

題目的唯一來源是 `spec.py`。改完後執行：

```bash
python3 build.py        # 重新產生 google-forms.gs 與 forms-spec.json
node build-docx.js      # 重新產生 .docx
```
